# Corpus Application Findings v0.3

**Asset:** AltisSports  
**Sprint:** Sprint 7  
**Status:** Provisional Cross-Corpus Findings — Not a Standard  
**Evidence base:** Reviewed BC-001–BC-020 v0.3 corpus

## 1. Executive Finding

Schema v0.3 is adequate for the current research corpus.

The additional relations remain useful when applied beyond their motivating cases, and no evidence-backed need for schema v0.4 appears in BC-001–BC-020.

Adequacy for research representation does not equal readiness for normative requirements.

## 2. Application Findings

### F19 — Agency Segments should remain sparse

Most cases have one stable performance regime. Creating multiple segments merely because the schema permits them would fabricate complexity.

Segments add value when control changes materially, as in BC-010, BC-017, and BC-019.

### F20 — Remote control and remote competition are different relations

BC-005 represents a pilot separated from a physical craft through a control and sensing channel.

BC-008 represents performers at separate physical sites sharing one synchronous computational contest state.

These relations should not be collapsed into one use of “remote.”

### F21 — Co-location is still an arena relation

BC-003, BC-011, BC-012, and BC-014 show that a distributed-arena structure can correctly record co-location. The field is not reserved for geographically remote systems.

This makes the absence of remote topology explicit without implying that the field is irrelevant.

### F22 — Heterogeneous object classes must retain unknown topology

BC-006, BC-007, and BC-009 include multiple event or product configurations. Selecting one topology for the entire activity cluster would violate object lock.

`unknown` is therefore an analytically correct result when the classified object is too broad.

### F23 — Participatory actors generalize beyond spectators

BC-003 and BC-016 show that non-performing information or supervision actors can materially affect conditions without becoming Performance Agents.

The relation is useful beyond BC-020, but it must remain limited to material rule, resource, information, trigger, or supervision effects.

### F24 — Intentional Biological Control remains intentionally narrow

No additional case beyond BC-018 requires the structure.

This supports keeping the field nullable and prevents physiological sensing in ordinary sport from being misclassified as intentional biological control.

### F25 — v0.3 does not close category uncertainty

The unified corpus still preserves:

- BC-018 as unresolved;
- BC-005 as partial/disputed for core spatial-athletic membership;
- heterogeneous product and event cases as object-dependent;
- remote distributed integrity requirements as unratified.

A schema succeeds when it records uncertainty, not when it removes it.

## 4. Schema Decision

No schema v0.4 is authorized by Sprint 7.

Future schema change requires a repeated representational failure, not a desire for completeness or version cadence.

## 5. Standardization Consequence

The corpus is now sufficient to define what the first ASR document may and may not attempt.

It is not sufficient to issue normative technical tolerances, certification, or category-conformance judgments.
