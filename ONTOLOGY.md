# AltisSports Ontology

**Version:** 0.1  
**Status:** Provisional Category Model — Not a Standard

## 1. Purpose

This ontology supplies the minimum vocabulary needed to describe Spatial Sport systems without collapsing activity, product, environment, performance, and evidence into one concept.

## 2. Root Entities

- **Activity:** structured participant actions under constraints.
- **Athletic System:** the arrangement through which performance is enabled, constrained, measured, and interpreted.
- **Spatial Athletic System:** an athletic system in which computationally mediated space has an operational role.
- **Experience:** a particular participant or spectator encounter with a system.
- **Product:** an implementation providing experiences or system functions.
- **Platform:** a technical environment supporting products or integrations.
- **Organization:** an institutional, commercial, research, or governing entity.

## 3. Human Roles

Participant, Athlete, Coach, Official, Spectator, Operator, and Rights Holder.

The term “athlete” does not by itself prove that the activity meets a formal definition of sport.

## 4. Space Entities

- **Physical Arena**
- **Computational Arena**
- **Unified Arena:** physical and computational arenas jointly affect one performance process.
- **Rule-Bearing Zone:** position or state changes what is allowed, scored, penalized, or measured.
- **Tracking Volume:** the region within which state can be detected with defined characteristics.

## 5. Performance Entities

Action, Performance, Metric, Measurement, Calibration, Result, and Profile.

A **Profile** is multi-dimensional and does not force all dimensions into one score.

## 6. Rule and Integrity Entities

Constraint, Rule, Computational Rule, Officiation, Integrity Condition, Comparability Condition, and Failure Mode.

## 7. Evidence Entities

Claim, Source, Evidence Record, Provider Claim, and Altis Interpretation.

## 8. Functional Roles of Systems

Competition, Training, Assessment, Rehabilitation, Simulation, Officiation, Measurement, Spectatorship, Broadcasting, Social Participation, and Research.

A training system is not automatically a sport, and a spectator system is not itself an athletic contest.

## 9. Environment Modalities

Physical, Digitally Augmented, Mixed, Virtual, Remote Distributed, and Hybrid.

## 10. Core Relations

- an Organization develops, operates, governs, funds, or owns a Product;
- a Product implements System Roles;
- a Participant performs an Activity through an Athletic System;
- an Athletic System operates within Arenas;
- a Rule constrains an Action;
- Officiation interprets rule-relevant events;
- Measurement produces a Metric;
- Calibration supports Comparability;
- a Claim is supported or challenged by an Evidence Record;
- a Failure Mode violates an Integrity Condition.

## 11. Classification Discipline

No entity is classified as Spatial Sport solely from branding, XR terminology, immersion, a 3D interface, device compatibility, or an unsupported provider claim.

Classification requires evidence of operational spatial integration and identification of the classified object: activity, system, product, experience, or event.

## 12. Deferred Terms

Sport threshold, spatiality level, embodiment score, integrity score, readiness level, certification status, and compliance status are deferred.

The ontology must describe before the standard judges.
