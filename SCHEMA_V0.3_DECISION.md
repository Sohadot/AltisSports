# Boundary Case Schema v0.3 Decision

**Asset:** AltisSports  
**Decision status:** Ratified for Corpus Use  
**Normative status:** Not an ASR Standard  
**Date:** 2026-07-24  
**Evidence basis:** `SECOND_STRATUM_FINDINGS_V0.2.md`, `TARGETED_BOUNDARY_DEEPENING.md`

## 1. Decision

AltisSports will issue `BOUNDARY_CASE_SCHEMA_V0.3.json` as an additive corpus schema.

The decision is based on representational insufficiency in v0.2, not on release cadence or branding.

## 2. Required New Structures

### `agency_segments`

Represents time-varying or regime-varying agency without forcing a whole contest into one summary label.

### `distributed_arena_relation`

Distinguishes co-located stations, remote synchronous performance, multi-hub events, asynchronous participation, and remote supervision.

### `participatory_actor_relations`

Represents non-performing actors who alter resources, constraints, information, or modifiers.

### `intentional_biological_control`

Represents intentional bodily-origin signal control while keeping Performance Agency and athletic embodiment separate.

## 3. Controlled Vocabulary Additions

The schema adds:

- `intentional_biological_control` to performance-interface types;
- `intentional_biosignal_control` to embodied-demand types;
- v0.3 migration and review statuses;
- carried-forward review states for v0.2 profiles and Spatial Functions.

## 4. Explicit Non-Changes

Schema v0.3 does not:

- add a total score;
- add a spatiality or embodiment level;
- define a maturity ladder;
- authorize certification or conformance;
- settle a minimum embodiment threshold;
- convert BC-018 into a Spatial Athletic System;
- treat a declared control regime as an observed agency transition;
- treat multi-site branding as remote synchronous integrity.

## 5. Historical Integrity

The following remain immutable:

- `BOUNDARY_CASE_SCHEMA.json`
- `boundary-cases-001-010.json`
- `BOUNDARY_CASE_SCHEMA_V0.2.json`
- `boundary-cases-001-010.v0.2.json`
- `boundary-cases-011-020.v0.2.json`

The v0.3 dataset is a separate derivative with explicit source and review metadata.

## 6. Standardization Status

`ASR-001` remains unauthorized.

Schema adequacy is evidence infrastructure. It is not a normative requirement set.
