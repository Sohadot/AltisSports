## Coverage Rule

A limited review wave is designed to cover at least four reviewer classes, including:

- one operational class from RC-01 or RC-02;
- one technical or measurement class from RC-03 or RC-04;
- one human-impact or methodology class from RC-05 or RC-06;
- RC-07 evidence and data governance.

This is a coverage condition, not a quorum, vote, or adoption threshold.

## Reviewer Assignment Rule

A reviewer can address any clause but receives a primary assignment matched to demonstrated experience.

No reviewer class can certify ASR-001 or override the approved scope.
