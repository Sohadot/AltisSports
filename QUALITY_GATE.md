# AltisSports Quality Gate

**Version:** 1.0  
**Status:** Ratified Release Gate

## 1. Universal Gate

### Purpose and Scope
- [ ] One explicit purpose and audience.
- [ ] Scope, exclusions, and status are visible.
- [ ] The artifact does not claim more than it addresses.

### Conceptual Integrity
- [ ] Terms agree with the ontology.
- [ ] New terms resolve a real gap.
- [ ] Provisional claims are marked.
- [ ] Ratified decisions are not contradicted.
- [ ] Boundary cases are acknowledged where relevant.

### Evidence and Claims
- [ ] Material claims have traceable sources.
- [ ] Provider claims are attributed.
- [ ] Analysis is distinguishable from fact.
- [ ] Time-sensitive claims carry dates or status.
- [ ] Limitations are visible.
- [ ] Citations support their attached claims.

### Strategic Value
- [ ] The artifact increases authority, intelligence, revenue capacity, or acquisition value.
- [ ] It is not a duplicate created for volume.
- [ ] A serious user can act or understand better because it exists.

### Commercial Integrity
- [ ] Paid relationships are disclosed.
- [ ] Payment does not determine judgment.
- [ ] No deceptive certification exists.
- [ ] Foundational public knowledge remains open.

### Versioning and Maintenance
- [ ] Version and dependencies are recorded.
- [ ] A correction path exists.
- [ ] Superseded information is not silently current.
- [ ] Maintenance responsibility is defined before operational release.

## 2. Public Web Page Gate
- [ ] One primary reference function.
- [ ] Original reference value.
- [ ] Title, H1, description, canonical, and structured data agree.
- [ ] No orphan page.
- [ ] No known broken links.
- [ ] Semantic HTML and no-JavaScript comprehension.
- [ ] Mobile, keyboard, screen-reader, reduced-motion, and performance checks pass.
- [ ] Visual effects do not hide indexable content.

## 3. Dataset and Atlas Gate
- [ ] Fields are defined.
- [ ] Provenance and temporal status are retained.
- [ ] Unknown is not encoded as false.
- [ ] Provider claims are separated from Altis classifications.
- [ ] Controlled vocabularies are versioned.
- [ ] Duplicate entities are resolved.
- [ ] Exports validate against a schema.
- [ ] Licensing is explicit.

## 4. ASR Gate
- [ ] Problem, scope, normative language, observable evidence, boundary testing, exclusions, revision, and appeals are defined.
- [ ] No external recognition is implied without evidence.

## 5. Tool Gate
- [ ] Output logic is documented.
- [ ] Inputs are validated.
- [ ] Outputs are explainable.
- [ ] Missing evidence does not become a negative score by default.
- [ ] Provisional theory is not disguised as precision.
- [ ] Version, date, methodology, privacy, failure, and uncertainty states are explicit.
- [ ] Outputs link back to reference material.

## 6. Release Decision

- **PASS**
- **CONDITIONAL PASS**
- **HOLD**

No artifact may label itself PASS without a recorded gate result.
