# AltisSports Interface Thesis

**Version:** 0.1  
**Status:** Foundation

## Thesis

> The interface must represent the arena as a governed spatial system in which body, rules, measurement, presence, and integrity remain connected.

The interface does not decorate the reference architecture. It makes the architecture perceptible.

## Conceptual Source

The historical Altis was a bounded environment holding multiple systems together: athletic action, ritual, spectatorship, identity, rules, and memory.

The AltisSports interface should reinterpret containment as system architecture rather than reproduce Greek ornament.

## Visual Grammar

Permitted conceptual elements include:

- arena boundaries;
- axes and fields;
- trajectories;
- calibrated grids;
- spatial layers;
- rule zones;
- measurement marks;
- nodes of presence;
- evidence links;
- system states;
- transitions between physical and computational space.

## Prohibited Defaults

Avoid:

- generic neon gaming aesthetics;
- metaverse stock imagery;
- avatar collages;
- casino visual language;
- decorative Greek columns;
- gratuitous 3D temples;
- glowing effects without semantic purpose;
- video backgrounds that weaken readability;
- interactions that conceal content from crawlers or assistive technology.

## Motion Doctrine

Motion may be used only to explain:

- transition of an activity between media;
- relation between body and arena;
- activation of a rule-bearing zone;
- propagation of measurement;
- comparison failure;
- loss of calibration;
- spectator presence;
- AS³ layer relationships.

Every motion must have a static equivalent.

## Technical Constraints

The public interface must be:

- semantic;
- static-first;
- progressively enhanced;
- keyboard accessible;
- screen-reader comprehensible;
- responsive;
- performance-budgeted;
- crawlable;
- indexable;
- usable without animation;
- usable without WebGL;
- resilient to script failure.

## Adoption Test for Advanced Visuals

A 3D or WebGL element is permitted only when:

1. it explains a concept;
2. the page remains understandable without it;
3. it works safely on mobile;
4. it does not weaken SEO;
5. it does not violate the performance budget;
6. it respects reduced-motion preferences;
7. it does not make the asset look juvenile or game-like;
8. it measurably improves comprehension.

## Governing Order

> Concept → Performance → Beauty
