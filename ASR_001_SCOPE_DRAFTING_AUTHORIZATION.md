# ASR-001 Scope Drafting Authorization

**Decision:** **AUTHORIZED FOR SCOPE DRAFTING ONLY**  
**Effective condition:** Sprint 7 validation and gate result are PASS  
**Normative status:** No standard is issued

## 1. Authorized Artifact

The next sprint may draft a scope document under the working title:

> **ASR-001 — Spatial Athletic System Evidence Profile**

The title is provisional until the scope is approved.

## 2. Candidate Problem

Organizations lack a consistent minimum structure for describing a Spatial Athletic System in a way that keeps object identity, Performance Agency, embodiment, operational spatial functions, comparison conditions, evidence, uncertainty, and governance visible.

The candidate first ASR should address that disclosure and evidence-profile problem.

## 3. Authorized Scope Questions

The scope draft may determine:

- which object is being profiled;
- which system roles are in scope;
- which AS³ fields belong in a minimum evidence profile;
- how provider claims and independent evidence are distinguished;
- how unknown, disputed, and not-applicable states are represented;
- how versions, corrections, dependencies, and limitations are disclosed;
- what the profile enables for procurement, research, comparison, and governance.

## 4. Required Exclusions

The scope draft must exclude:

- a universal definition of sport;
- a minimum embodiment threshold;
- a total score or maturity level;
- product ranking;
- automatic category certification;
- clinical efficacy requirements;
- remote synchronous latency or calibration tolerances;
- final BCI athletic membership;
- causal-attribution scoring;
- safety certification;
- federation recognition;
- paid favorable classification.

## 5. Permitted Use of Boundary Cases

Boundary cases may:

- justify fields;
- expose exclusions;
- provide informative examples;
- test whether the scope is overbroad.

They may not be converted into a hidden scoring rubric.

## 6. What Remains Unauthorized

Sprint 7 does not authorize:

- normative requirements drafting;
- conformance clauses;
- certification marks;
- an implementation assessment;
- ASR-001 publication as a standard;
- claims that AltisSports has industry adoption.

## 7. Exit Condition for the Next Sprint

The ASR-001 scope draft must pass a separate scope gate before any requirements drafting begins.
