# ASR-001 Candidate Normative Core Gate

**Version:** 1.0  
**Applies to:** Sprint 10 Working Draft artifacts

## Gate Criteria

### N01 — Authorization
Clause authoring is authorized by the Sprint 9 gate and DEC-012.

### N02 — Stable clause set
The Candidate Normative Core contains exactly 30 clauses with stable D01–D15 identifiers.

### N03 — Scope alignment
Every clause remains inside the approved ASR-001 scope.

### N04 — Candidate normative language
Every clause uses explicit candidate normative language and remains labeled non-public and unpublished.

### N05 — Applicability
Conditional clauses map to explicit feature triggers and applicability states.

### N06 — Verification
Each clause retains verification modes and a candidate verification statement.

### N07 — Clause-to-field mapping
Every clause maps to a field path in the candidate profile model.

### N08 — Model independence
The implementation profile model is clause-derived and does not silently inherit the research corpus schema.

### N09 — Synthetic implementation
At least two synthetic profiles exercise local and distributed configurations.

### N10 — Deterministic validation
Local validation checks structure, trigger logic, evidence references, clause coverage, and prohibited scoring or certification keys.

### N11 — Conformance boundary
Any conformance result concerns the profile document or instance only.

### N12 — Exclusions
No score, maturity level, vendor ranking, safety or clinical certification, final BCI classification, unsupported tolerance, or public adoption claim exists.

### N13 — Historical integrity
Earlier schemas, datasets, scopes, catalogs, and gate records remain unchanged.

### N14 — Publication hold
ASR-001 remains a non-public Working Draft.

## Decisions

- **PASS — AUTHORIZE INTERNAL IMPLEMENTATION TRIALS ONLY**
- **CONDITIONAL PASS**
- **HOLD**

A PASS does not authorize Public Review, publication, certification, or external conformance claims.
