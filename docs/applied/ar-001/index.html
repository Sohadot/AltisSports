What is being inspected?

World Taekwondo-governed Virtual Taekwondo contest configuration, as specified by the WT Virtual Taekwondo Rules and Regulations, Version 4.0 (dated 11 April 2026), operating as a co-located multi-station Field of Play under WT promotion or recognition, using the official WT Virtual Taekwondo technology-provider stack.

Short label: WT Virtual Taekwondo contest configuration (Rules v4.0 / co-located FOP). Performance window: from Game Master start of a round (Shi-jak) until knockout, time expiry, disqualification, or authorised stop. Frozen 27 August 2026. This lock does not overwrite BC-015.

Claims must not slide between adjacent objects. AS³ is allowed to inspect only the frozen contest configuration here. Neighbouring objects may be named as context. They do not inherit contest findings.

Activity

Practising or playing Virtual Taekwondo, including training and practice modes. Out of scope as the classified object.

Competition format

Best-of-3, 60-second rounds, Health Bar, stun, break, categories as written in Rules v4.0. In scope as the rule-bearing format of this contest.

Technical system

AXIS nodes, compatible PICO headsets, Game Master PC, VTKD clients, dedicated local network — only insofar as they run a WT-recognised match.

Event / deployment

Named championships (Singapore 2024, Chuncheon 2026, and others) are staging evidence. They are not the classified object.

Governing organisation

World Taekwondo, member bodies, and the official technology provider. Context for authority, not the inspected object.

Why this case matters

Virtual Taekwondo is useful because several Spatial Sport joints are public enough to inspect and still unfinished enough to remain honest. Live human kicking is coupled to wearable tracking, a shared computational arena, federation sporting text, software-executed constraints, and hybrid officiation — on separate clocks.

  1. L1–L2

    Human performance

    Live kicking and blocking on a mat. Agency is evidenced; “full-body” is not.

  2. L5

    Sensing

    Five AXIS nodes plus headset. Calibration is a validity gate, not setup trivia.

  3. L3

    Computational arena

    Two physical stations, one match state. Constitutive, co-located, not remote.

  4. L4

    Rule execution

    WT text and VTKD code. They can diverge. That is the inspection.

  5. L7

    Outcome

    Software computes HP; humans stop, restore, and officialise. Formula unpublished.

Evidence boundary

Two artefacts are current for this inspection. They are not the same artefact.

  • WT Rules Version 4.0 (11 April 2026) — latest public WT rulebook found as of 27 August 2026. Version 3.0 (30 May 2025) is superseded. No later public rulebook was found. This is not a claim that no later internal or unpublished governing text exists.
  • VTKD v1.3.0 (21 August 2026) — latest public provider implementation documentation examined (user manual, game mechanics, patch notes). This is not a statement that v1.3.0 was the software build used at any named WT event.

No public event-to-build lock was found. Internet at a court is not evidence of geographically distributed opponents. Marketing copy remains attributed provider speech.

AS³ inspection

L1

Performance Agency

WT governing
Question
Who performs in the round, and is live human skill causally necessary to the result?
Evidence establishes
Athletes must be on the mats, calibrated, and execute kicks (and block/stun-building actions) in a live round. Absence when called loses the match. Tampering with PC, headset, controllers, or trackers is prohibited.
Evidence state
Documented for live human agency in the performance window. Unknown for undeclared automation inside hit detection.
Altis interpretation
Live human Performance Agency is evidenced for this contest object. Hardware design is not in-performance agency. Officials are not performers. An older GM “force victory” control is an override channel; whether it is enabled in WT tournament mode is unknown.
Unresolved
Whether closed-source smoothing or inverse kinematics can generate scored limb motion the athlete did not perform.
L2

Performance Interface and Embodied Demand

Provider-documented
Question
How does skill enter, and what bodily demand is constitutive rather than scenic?
Evidence establishes
Required court interface: VR headset and controllers; five AXIS nodes on spine, thighs, and shins; T-pose calibration; 4 m × 4 m area; 60-second rounds. Damage depends on strike acceleration. Physical hitting is prohibited.
Evidence state
Partial. Interface documented. “Full-body capture” is a provider phrase. Embodiment profile is qualitative.
Altis interpretation
The kicking channel is strongly evidenced as embodied. Arm blocking is likely controller- and/or IK-mediated because arm nodes are not required. Provider claims that strength and age no longer influence outcomes conflict with acceleration-based damage and with age categories in the rules.
Unresolved
Authoritative sensor for forearm block; punch tracking path; quantitative workload or cybersickness data.
L3

Arena and Spatial State

WT governing
Question
What arenas exist, and is computationally mediated space constitutive?
Evidence establishes
Two 4 m × 4 m mats at one venue, ≥ 2 m apart; shared Game Room; avatars; virtual start marks; automatic break on avatar proximity; headsets on the same local Wi-Fi as the Game Master. Maximum two courts in current manuals.
Evidence state
Documented for a co-located unified arena. Geographically distributed remote arena: not evidenced.
Altis interpretation
Computational match state is constitutive: if it fails, the round cannot proceed as specified. Physical mats remain constitutive for safety and tracking volume. Global events and an internet uplink do not establish remote topology.
Unresolved
Whether virtual geometry is a faithful metric of the mats, and whether Boundary Damage is used in WT events.
L4

Constraint and Rule Execution

Altis interpretation
Question
Where do rules reside, and how do they become operative?
Evidence establishes
WT Rules v4.0 is the written sporting code. Software computes HP, stun, automatic break, and some draw order. Humans inspect, warn, disqualify, restore, and officialise. VTKD v1.3.0 post-dates the rulebook.
Evidence state
Partial. Hybrid execution documented. Version lock between rules and build is not public.
Altis interpretation
Declared rules and implemented rules can diverge. That is not a finding that any event was invalid. It is the L4 condition AS³ exists to record.
Unresolved
Which authority wins when patch notes and Articles 5.x disagree; whether Boundary Damage is on in WT competition.
L5

Sensing, Tracking, and State Estimation

Provider-documented
Question
What does tracking actually observe, and how do calibration, drift, and loss affect valid state?
Evidence establishes
AXIS IMU/magnetometer nodes; headset dongle; in-game T-pose; site assessment drift ≳ 10° unacceptable. Surface Calibration was introduced then withdrawn in v1.3.0 because event-site magnetic environments caused inaccurate leg tracking. Automatic GM-Timeout on node/headset/controller/dongle disconnect is documented in v1.3.0, not as a WT event-build fact.
Evidence state
Partial. What is worn and how it fails is documented. Accuracy, sampling, and estimator internals are not.
Altis interpretation
Sensing is constitutive. Magnetic environment and calibration are part of contest integrity. Five body nodes plus HMD is not an unqualified proof of full-body capture. Occlusion-proof is an attributed claim.
Unresolved
How kick acceleration is derived; how much scored limb motion is estimated rather than measured.
L6

Measurement and Comparability

Unknown
Question
How do observations become metrics, and under what conditions is comparison valid?
Evidence establishes
HP 0–1000; stun 0–500; Low/Medium/High acceleration bands; head vs body; draw order. Shared equipment class at a co-located venue after accepted calibration. No weight classes in Rules v4.0; age and mixed-gender categories exist.
Evidence state
Partial. Qualitative pipeline documented. Formula and thresholds unpublished.
Altis interpretation
Shared equipment class is not demonstrated metric equivalence. Comparability is engineered and incomplete even locally. Remote comparison is not evidenced. Acceleration scoring preserves a physical performance component.
Unresolved
Numerical thresholds, firmware locks, magnetic pass/fail tied to results, character-model hurtboxes.
L7

Officiation and Outcome

WT governing
Question
How do rule-relevant events become decisions, and who can correct them?
Evidence establishes
Software computes HP, stun, KO, and draw criteria. Referee declares the winner. Technical Delegate officialises. After 20 seconds of unrecoverable disconnection the leading player may be awarded the round regardless of HP margin.
Evidence state
Documented for role split. Partial for contestability and reproducibility from logs.
Altis interpretation
Outcome is hybrid. Many scoring events appear non-reviewable except via timeout or equipment swap. Discretion after disconnection is a governance choice, not a measured integrity bound.
Unresolved
Protest path for VTKD scoring errors; tournament status of any GM force-win control; log reproducibility.
L8

Presence and Participation

WT governing
Question
Who perceives, communicates, and can affect the system without being the performer?
Evidence establishes
Co-located roles: two athletes, coaches, Referee, Game Master, two Technical Operators, Technical Delegate, medical cover, spectators via required displays. Coach technical timeout once per match. Immersion is present.
Evidence state
Documented for co-located roles. Remote athlete participation: not evidenced.
Altis interpretation
Presence is not Spatial Athletic System membership. A spectator client is not a distributed competitor. Internet-connected local courts are not geographically distributed competition.
Unresolved
None that changes the frozen topology.
L9

Safety, Accessibility, and Human Limits

Unknown
Question
What physical, cognitive, and access conditions are actually evidenced?
Evidence establishes
Non-contact rule; medical cover; mats and safety distances; hijab permitted; mixed-gender and age categories; anti-doping. Format facts are not para classification.
Evidence state
Partial for conventional safety procedures. Systematic accessibility / adaptive classification: not evidenced.
Altis interpretation
Inclusion rhetoric is not a documented para/adaptive classification architecture. Removing weight classes is a format choice. VR donning, 4 m kicking, acceleration scoring, and a visual HUD remain barriers unless separately evidenced.
Unresolved
Cybersickness protocol; adaptive equipment; sensory or mobility variants.
L10

Governance, Evidence, and Change

Altis interpretation
Question
Who owns the contest, how do versions change, and what can an external inspector see?
Evidence establishes
WT is the sporting authority. Refract Technologies / Virtual TKD Pte. Ltd. is named as official technology provider. Patch notes and manuals are public. Source code, damage tables, and mandatory build IDs are not.
Evidence state
Documented for authority and provider identity. Partial for change-control and external inspectability.
Altis interpretation
Federation rule text and software behaviour can move on different clocks (Rules v4.0 in April 2026; VTKD v1.3.0 in August 2026). AltisSports claims no commercial relationship with WT or the provider in this case.
Unresolved
Public software–rules version matrix; athlete motion-data rights; correction log for scoring defects.

Material rule / implementation divergence

The following rows compare WT Rules v4.0 with VTKD v1.3.0 public documentation. They do not establish that an event was invalid. They establish that declared sporting rules and public implementation documentation are not fully synchronized.

Topic WT Rules v4.0 VTKD v1.3.0 (provider docs)
Stun activation Next successful strike after 500 stun points. Punches no longer trigger stun; next successful kick activates. Punches may still fill the meter.
Groin-kick damage Not specified as an illegal-scoring exclusion in the examined articles. Damage no longer counted from illegal groin kicks.
Surface Calibration Not in WT text. Calibration is a human-checked procedure. Introduced in 1.2.34 documentation; withdrawn in 1.3.0 as unstable at event sites.
GM-Timeout Disconnection policy is Technical Delegate / Referee procedure. Automatic GM-Timeout on headset, controller, dongle, or node power-off/disconnect.
Boundary Damage Not in WT Articles 1–6. Toggleable software setting. Use in WT events unknown.

What remains unknown

Unknown is an inspection result. It is not a low score.

  • Scoring formula and acceleration thresholds (numerical HP bands unpublished).
  • Mandatory software build per event. No public event-to-build lock was found.
  • Tracking accuracy, sampling, fusion, and estimator internals.
  • Arm / block sensing path (controller pose vs IK versus optional extra nodes).
  • Remote distributed contest integrity (latency budget, cross-site calibration, remote officiation).
  • Event-level firmware and version lock for AXIS, headset, and VTKD clients.
  • Accessibility classification and accommodation architecture.
  • Athlete motion-data rights.
  • Reproducibility of a round from logs.

What would change the profile?

An applied reference is revisable. The object lock itself would change if any of the following were evidenced:

  • A later WT rulebook than Version 4.0 governs WT-recognised Virtual Taekwondo.
  • WT-recognised matches are routinely geographically distributed.
  • WT disclaims the VTKD software and officiates kicks by other means.
  • The official stack is no longer AXIS plus listed VR headsets.
  • Practice or home VTKD without Game Master / Field of Play is declared the same object as championships.

BC-015 still records what would change the remote-distributed finding: published remote match rules, latency budgets, calibration procedures, and evidence of competitors in different physical sites sharing one match. That package was not found as of 27 August 2026. not_evidenced is retained, not converted into impossibility.

Method and limitations

This page is an applied reference case. It is not a product review, certification, conformance assessment, ranking, score, sport-recognition verdict, endorsement, or independent laboratory validation.

  • AR-001 does not overwrite BC-015. BC-015 remains the corpus record.
  • BC-015’s C5 category finding remains attributed to the corpus. AR-001 does not issue a new category verdict.
  • ASR-001 remains an unpublished Working Draft. CITE-HOLD-ASR-001 remains unaffected.
  • Zenodo v0.1 is the frozen conceptual foundation. It is not this inspection.
  • Provider manuals, mechanics pages, patch notes, and marketing remain C3 where the Source and Claim Policy requires it.
